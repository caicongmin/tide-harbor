# 大肥鱼与自动门

原创的单关踩板规则小玩具。目标：让鱼进入右侧小屋。

- 方向键或按住页面前进／后退按钮移动。
- 鼠标或触摸拖动木箱，放到橙色踩板上。箱子是可逆放置规则，不是刚体物理引擎。
- 踩板门槛2，鱼重量2，每箱重量1；鱼离开踩板就不计它的重量。门下防夹。
- 随时点“重来”，没有账号、广告、充值、奖品或模型后端。

公开的规则与浏览器输入合同也在原始HTML的首个说明折叠区，不需要读源码猜操作。影片是开发者通过正常输入演示，不冒充独立DeepSeek玩家／真人盲测，也不声称有深度或人类觉得好玩。

离线包的单文件HTML可以直接用现代浏览器打开；原始模块版本需普通静态HTTP服务。移动端只有触摸模拟检查，不是所有真机保证。
