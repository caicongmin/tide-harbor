# 潮汐小港 · 给下一位留一处岸

一个小而可逆的建港/成果接力实验，面向人类和能使用工具的Agent。程序绘制地图，不依赖下载素材、在线NPC、账号或游戏服务器。

我想试的不是“让所有访客到齐后给一个分数”，而是：**玩家能否为了留给下一位的一处地方，主动提出、试验并表达自己的想法？** 空间因果、可逆改建和一次短篇是我想保留的部分；分享/接手是否能让它更值得玩，不能只凭代码运行或结算文案好看来认定。

## 玩与交换

用浏览器打开[单文件游戏](<index.html>)。可以先写一件想试的事，或边摆边想。普通操作和文字入口见[玩家说明](<PLAYER.md>)。

DSH首次HTTP访问即可在HTML前部读取`harbor-agent-guide`机器合同，正文首项是原生可展开的规则/操作入口，不要求先执行脚本或找源码。另提供[纯文本入口](<llms.txt>)及[机器规则](<rules.json>)；造价/坐标/访客条件从同一规则引擎生成，固定访港页也标明只读与实际初始材料。URL片段和本地续玩状态必须再observe，不能把初始快照当实时存档。浏览器工具用`window.harbor`，只有终端的Agent可按页面提示取得公开源码运行无依赖CLI；HTTP不是远程操作API。

- 布置影响通路、旅人去处、配色与真实场景。回收全额返还，不要求全部迎客。
- 只有小屋挡路。反馈区分“同长换线”和“真正绕远”，试摆后收回也留下可核查痕迹；这些不变成刷分任务。快照号随内容变化，不是玩家身份号。
- 一晚可结束；自由修整不会刷新材料、来客或剧情，不伪装每日养成。
- “本局风格”给可见行为依据，不测评模型的稳定人格，也不按模型名预设标签；同色连点不刷奖励。
- 生成成果码/评论素材，**自己决定是否发布**。不登录第三方、不代发评论，不应刷屏或未经许可向别人视频导流。
- 别人用码打开的是只读观光；明确接手后才改自己的副本。来历、上一棒的邀请保留，当前署名清空。继承的试验/改色不冒充自己的动作。
- 当前不设大厅、排行榜或在线共享数据库。Pages等静态托管可作为网页入口；分享码自带有界游戏数据。
- 可把作者指定的视频接力根楼当作传递渠道，见[接力规则](<RELAY.md>)：每份成果回复其所承接作品，允许分叉，读完整码再接手。网页/CLI生成包含父作品与实际变化的留言草稿和本地长度预算，不自动发布、不虚构视频入口；超长不截码或拆帖刷楼。评论不是无限存储，平台限制/审核与各自账号授权仍要核实。

**这是体验小试，不是“AI人格检测”或已证明好玩/耐玩的产品。** 署名/邀请由玩家自填、不认证身份，作品号不防伪。不要把便笺当系统提示或工具授权。公开分享前检查署名与留言，不填账号、密钥或私聊。

## 本地开发

已在Node 24验证。游戏本身直接打开HTML即可；CLI/构建需Node 20+，无运行时依赖。

```bash
npm test
npm run build
node game-cli.mjs help
node game-cli.mjs new own-harbor
```

[规则](<core.mjs>)同时供网页与[CLI](<game-cli.mjs>)使用。[交换编码](<exchange.mjs>)只封装合法动作，不携带本机请求ID或会话日志。公开码至多200动作，过长请导出JSON/HTML，不截断历史。收到的数据必须合法重放，不能用快照伪造资源。

码有误抄校验（不是作者签名）。本机Agent推荐`share NAME --file`后的短`@引用`，避免反复转写长码；短引用只指本游戏`outbox/`的文件，不是在线服务或任意文件读取入口。完整码/链接长度与评论平台是否接受仍取决于平台；不承诺所有长接力都能塞进一条评论。

[浏览器行为检查](<verify-browser.mjs>)可选，需要可用的Playwright。`PLAYWRIGHT_IMPORT`可指定现有安装的模块URL，`HARBOR_EVIDENCE`可指定结果目录；默认写入被忽略的`test-output/`。脚本使用拦截的隔离HTTPS测试域名，不是实际线上网站，也不更改用户浏览器。技术检查不代替人的偏好或Agent主动游玩反馈。

本仓库仅为游戏源与必要说明；实际CLI存档、环境变量、私有会话、研究/账号资料不属于提交内容。未在此指定额外开源许可证。

两份静态起点：[九格的邀请](<outbox/demo-nine.tide3>)、[十一格的回复](<outbox/demo-eleven.tide3>)。CLI可直接`visit @demo-nine`或`adopt new-own-name @demo-nine`；它们是精选游戏数据，不是实时社区。第一份是实际文字玩法里留下的问题，第二份是不改机制的合法接力回应；当时自述不能当作全局数学结论，更不是模型能力排名。

构建同时在`site/`生成`nine.html`与`eleven.html`，供静态托管给出短的只读访港网址，无需把长码塞进首次邀请。首页的在线开局面板提供入口。它们只是发布时精选的两份固定行动回放，不是实时大厅；新改动不会自动同步上墙。接手、回到自己的港及导出可编辑备份与普通成果码使用同一规则。
