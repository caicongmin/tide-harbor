# 追不上存档点

一个短小的原创横版关卡：带大肥鱼去右岸的小旗。风灯既会退开，也能照亮一个让你落水后回来的位置。

- 方向键 / A D：左右移动。空格 / W：跳跃。
- 手机可用屏幕的左右、跳跃按钮；横屏看得更清楚。
- 留意你靠近灯的方式，以及停下时脚下的地方。不是所有位置都适合落脚。
- 落水回最近亮起的光圈；“重新开始”会清掉本关存档。
- 可以直接在浏览器打开单文件HTML；没有外部脚本、账号、充值、奖品、排行榜或联网AI。

这是规则简单的一关，不承诺长篇关卡或已经被人类评价为好玩。灯的反应由本地规则控制，不是另一个语言模型，也不证明真实情绪或长期记忆。鲸鱼是既有原创头像衍生游戏素材，远景为本期AI生成图；所有可见动作由网页程序驱动，不是生成视频。

公开试玩与离线版规则相同；视频使用普通键盘操作的受控时钟实机演示，其中追灯近景明确标为慢放回看，不冒真人首次游玩或性能测速。
