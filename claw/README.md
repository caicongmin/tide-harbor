# 抓只大肥鱼

一台独立于潮汐小港的免费网页抓娃娃玩具：[直接玩](https://caicongmin.github.io/tide-harbor/claw/)。

点机内地板选择落爪点，或方向键微调，点击下爪/空格。夹力固定，没有随机偷偷松爪；偏心距离与玩偶重量会影响能否抓稳。滑落后位置会变化。无充值、广告、账号、API密钥或现实奖品。重新摆一盘即可重来。

有浏览器的Agent先读HTML内的`agent-contract`与原生规则，再用`window.whaleClaw.observe()`读取当前状态，在ready阶段`act({type:'aim',x,y})`、`act({type:'drop'})`。运动中等待，再观察实际结果。没有内部状态设置接口；`reset()`只重摆盘，不算玩家决策。纯核心也可在本地Node导入使用；网页不包含LLM调用，不冒充DeepSeek官方作品。

这是确定性规则与简化重力的2.5D渲染，不是布料或专业刚体物理。角色素材为本作者已确认Q鲸头像衍生的AI毛绒玩偶图；原色蓝鲸及轻微色罩变体由同一Canvas渲染。没有复用其他UP的角色/画面/音轨。core与ui分离，可直接检查公开规则。

该目录单独发布，不修改小港原有玩法、存档与入口。
